# Product

## Register

brand

## Users

The Space is the public face of a portfolio project. The primary audience is **recruiters, technical reviewers, and peers** judging whether the team can ship. They land via a GitHub README link or a LinkedIn post, scan the page in 30 seconds, decide if it's worth a deeper look. Secondary audience: Arabic NLP enthusiasts and Saudi food-business operators who arrive curious and may actually try classifying their own complaints.

## Product Purpose

Demonstrate that an 8-class Arabic restaurant complaints classifier (95.05% test accuracy, Saudi-Gulf dialect) was built end-to-end by the AI Club team. The Space is the artifact — the model, the methodology, the polish all need to read as "production-grade, not student project." Success = a recruiter spends >30 seconds, opens the GitHub repo, and remembers it tomorrow.

## Brand Personality

Warm, hospitable, Saudi-rooted. Confident without flash. The aesthetic is closer to a thoughtful neighborhood restaurant or a magazine spread about Saudi food culture than to a SaaS dashboard. Three words: **hospitable, considered, rooted.**

## Anti-references

- Generic dark + neon green SaaS / "AI dashboard" look (currently deployed — replacing it)
- Heavy Arabic-cultural ornamentation: geometric Islamic patterns, gold-on-green, royal typography. Feels kitsch for an NLP tool.
- Bare default Gradio look — no branding, looks like a debug page
- Rashidbm/saudi-date-classifier — friend's Space, similar domain, different aesthetic; deliberately differentiate

## Design Principles

1. **Hospitable over impressive.** Earth tones and generous spacing over high-contrast and glow. Reads like a place, not a tool.
2. **Saudi without ornament.** Cultural context comes through palette and typography choices, never decorative flourish.
3. **The model is the hero.** UI gets out of the way of the prediction. No competing visual elements next to the result.
4. **Confidence through restraint.** One strong typographic move, one accent, one layout idea. No second hero.
5. **RTL-first, bilingual-respectful.** Arabic copy leads, English supports. Both should look intentional, neither should feel translated.

## Accessibility & Inclusion

- WCAG AA contrast on all text (min 4.5:1 for body, 3:1 for large)
- RTL-first layout — Arabic is the primary language, English labels secondary
- Tajawal webfont (Arabic + Latin in one family, no font swap on language change)
- Reduced motion respected (no autoplay, no large animated decorations)
- Keyboard-navigable (textbox, submit, examples all reachable via Tab)
